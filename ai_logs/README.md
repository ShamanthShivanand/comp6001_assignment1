# AI Logs

This folder documents all AI-assisted support used in this project.

It is included to support responsible AI use, attribution, reproducibility, and transparency.

## Files in this folder

- `prompts_used.md` – prompts used during coding, debugging, report refinement, and presentation preparation
- `ai_output_register.md` – summary of where AI-supported outputs were used and how they were reviewed
- `ethical_reflection.md` – reflection on attribution, privacy, bias, licensing, and academic responsibility

## Scope of AI Use

AI tools were used only as support tools for:
- code debugging
- code explanation
- report structuring
- slide planning
- GitHub and documentation support

AI was not used to fabricate results. All final experimental outputs, tables, metrics, and conclusions came from actual notebook execution and manual review.
