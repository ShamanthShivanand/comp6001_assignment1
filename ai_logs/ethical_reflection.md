# Ethical Reflection on AI Use

AI tools were used in this project as support tools for coding assistance, debugging, documentation, writing refinement, and presentation planning.

## Attribution and Transparency
All major uses of AI support have been documented in this folder. Prompts and usage summaries were recorded to maintain transparency and reproducibility.

## Human Review
All AI-generated code and text were manually reviewed before use. Code was tested in the notebooks, and written material was edited to reflect the actual experimental design and findings. AI outputs were treated as drafts rather than final authority.

## Accuracy and Fabrication
AI was not used to generate fake metrics, fake images, or unsupported conclusions. All reported values in the report and presentation came from actual notebook execution and dataset evaluation.

## Bias and Interpretation
AI-generated explanations may contain oversimplification or bias. For this reason, technical explanations and interpretations were checked against the project results and standard computer vision concepts before inclusion.

## Privacy
This project used public academic datasets and did not involve private, personal, or sensitive user data. No private data was shared with AI systems during the assignment.

## Licensing and Responsible Use
Public tools and libraries were used for academic purposes only. Where AI-assisted text or code contributed to the workflow, that assistance has been disclosed in this folder. Final responsibility for the submitted work remains with the student.

## Final Statement
AI support improved workflow efficiency and clarity, but the implementation, testing, result analysis, and final conclusions were the student’s responsibility.
